FAQ

        
Good to know.

        
Short answers about snippet files, dollar signs, and prefixes.

      

      

        

          Where do I put the generated file?
          
Save the downloaded .code-snippets file in your VS Code snippets folder, or open the Command Palette and run Preferences: Configure User Snippets. You can paste the JSON into an existing snippet file as well.

        

        

          Why is my dollar sign escaped?
          
VS Code uses $ for tab stops and variables. The converter escapes dollars that are not snippet syntax, so code such as $('.item') or ${name} stays intact. Turn off “Keep placeholders” to escape every dollar sign.

        

        

          What is a prefix?
          
The prefix is the shortcut you type in the editor to insert the snippet. For example, a prefix of greet lets you type greet, press Tab, and expand the snippet.

        

        

          Is my code uploaded anywhere?
          
No. There is no server, account, or analytics. The conversion runs entirely in this browser tab.
